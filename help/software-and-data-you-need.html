What software and data do I need to run Agency OS?

IntegrationsAgency OSUpdated September 2026

The seven tools Agency OS reads from, what each one costs, what to collect from every client, and two stacks priced out.

Agency OS is $199/mo flat and includes the CRM, project management, content board, links tracker, Today view, team capacity, the client reporting portal, the Claude connector, email logging, file storage, and the audit engines. What it does not include is the data. The Performance tab, the Website Quality Audit, the Local SEO audit, and Proposals all read from tools you already own or can sign up for in a few minutes.

You set each one up once under Settings → Integrations. One API key per tool, agency wide. Every client rides on the same keys, and clients never see them.

Prices below are list prices from each vendor's pricing page as of September 2026. Vendors change plans often, so verify before you budget. There is also a visual version of this page with screenshots you can share with your team.

Required

Claude Required

Runs the Agency OS connector. Create tasks, apply project plans, pull reports, and ask "what should I work on today" from Claude Desktop.

Who needs it

  • Anyone who wants to talk to Agency OS through Claude
  • Reporting-only staff can skip it

Price

  • Pro: $20/user/mo ($17 on annual)
  • Team: $25/seat/mo standard, $125/seat premium
  • Free tier works for light use

Data you need: Nothing. Sign in and connect.

Windsor.ai Required

One key that brokers every Google and social source: GA4, Search Console, Google Business Profile insights, Google Ads, Bing Ads, Meta Ads, TikTok, YouTube, LinkedIn, X, Facebook Pages, CallRail. Powers the Performance tab, WQA, and Local SEO audits.

Price

  • Standard $118/mo: 7 data sources, 75 accounts
  • Plus $299/mo: 10 sources, 200 accounts
  • Professional $598/mo: 14 sources, 500 accounts
  • Annual saves about 16%

How to size it

  • "Data sources" are connector types. GA4 is one, GSC is one, Meta is one
  • "Accounts" are client properties
  • A 20-client SEO plus paid shop fits Standard. Add paid and organic social and you need Plus
  • Free tier keeps only 30 days of history, so it will not fill a 12-month trend

Data you need: Connect each client's GA4, GSC, GBP, and ad accounts inside Windsor first. Agency OS auto-detects them.

Ahrefs or SEMrush Required

Rankings, keywords, backlinks, and domain metrics. Used by WQA, Proposals, Local SEO audits, and the SEO Performance tab. If both are connected, Agency OS uses Ahrefs.

Ahrefs

  • Lite $129/mo, Standard $249/mo, Advanced $449/mo
  • API and MCP access included on all plans
  • Rows per request: Lite 100, Standard 250, Advanced 500
  • Standard is the sweet spot for audits

SEMrush

  • Advanced plan required for API, about $456/mo billed annually
  • API units are bought separately on top
  • Ahrefs is the cheaper path if you are starting fresh

Data you need: The API key, plus each client's root domain

Screaming Frog Required

The site crawl you upload into a Website Quality Audit. Agency OS reads the export and turns findings into the plan.

Price

  • Free up to 500 URLs
  • Licence £199/yr per user (about $260) for unlimited crawling

Data you need: A crawl export of the client site

Tip: One licence for the person who runs audits is enough. The rest of the team never opens it.

Not required (depends on what you sell)

Local Falcon Not required

Map-pack grid scans. The core dataset for Local SEO audits and the local rank section of reporting.

Price

  • Starter $24.99/mo: 7,500 credits
  • Basic $49.99/mo: 15,150 credits
  • Pro $99.99/mo: 31,250 credits
  • Premium $199.99/mo: 63,150 credits
  • API included on all plans. Annual is roughly two months free

How to size it

  • A 7x7 scan is about 49 credits, a 13x13 is 169
  • Weekly scans on 3 keywords for 15 locations lands around Pro

Data you need

  • The API key
  • Each client's Google Place ID, or leave it blank and we match by website domain

DataForSEO Not required

Google Business Profile data, reviews, and keyword SERP sweeps for Local SEO audits. Replaces the need for GBP OAuth.

Price

  • Pay as you go, $50 minimum deposit
  • Business Data and SERP calls cost fractions of a cent each
  • Most agencies spend under $20/mo

What it replaces

  • Skip the "Google Business Profile (direct)" integration
  • DataForSEO covers profile and reviews without OAuth

Data you need

  • API login (email) and API password from DataForSEO → API Access
  • These are not your dashboard login

Google Workspace Not required

Drive client folders, the Links workbook in Google Sheets, and Gmail for email logging.

Who needs it: The agency account that owns the client folders

Price

  • Business Starter $6/user/mo
  • Business Standard $12/user/mo
  • 16% off on annual

Data you need

  • The Drive folder where client folders get created
  • The Links workbook URL

What to collect from each client

Fill these in on the client's Data tab so every report populates. See Connecting a client's data sources for where each field lives.

  • Every client: website root domain, GA4 numeric property ID (not the G- measurement ID) with Viewer access granted to your agency account, Search Console property with access granted, CMS and hosting logins (stored in the Overview tab).
  • Local SEO: Google Business Profile location ID(s) with Manager access, Google Place ID(s) for Local Falcon, CallRail account ID if they track calls.
  • Paid search: Google Ads customer ID (123-456-7890) with read access to your MCC, Local Services Ads account ID(s), Microsoft Ads account ID.
  • Paid social: Meta Ads account ID (act_ prefix) with partner access via Business Manager, TikTok Ads advertiser ID, YouTube Ads (the Google Ads ID that runs them).
  • Organic social: Instagram Business account ID, Facebook Page ID, YouTube channel, TikTok, LinkedIn page, X account.
  • E-commerce: Shopify store domain and GA4 with purchase events firing.
If a report comes back empty it is almost always one of two things: the client never granted access to the property, or the account is connected in Windsor but not selected on the client's Data tab. See My performance report is empty.
