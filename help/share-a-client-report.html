Sharing a read-only report with a client

Clients & ProjectsAgency OSUpdated September 2026

Create a public report link, choose which sections appear, and optionally protect it with a passcode.

Open the client and click 🔗 Share in the header. From the share manager you can:

  • Create a read-only public link to the client's Performance report.
  • Choose which sections are included.
  • Add an optional passcode.

Sections you've hidden with the report's ⚙ Sections dropdown stay hidden in shared links too, so you can trim a report for a client without affecting your internal view.

Shared reports show the same data as your internal view and refresh on the same schedule (cached about 20 hours, refreshed each morning). If a client says their report looks stale, hit ↻ Refresh on the report. See Data is stale or the report won't refresh.
