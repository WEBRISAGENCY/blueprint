What It Does

The Onboarding Agent handles the entire transition from closed deal to active client. Instead of spending hours manually building intake forms, sending access request emails, setting up project folders, and compiling kickoff documents, the agent runs the full sequence in minutes.

You give it a signed proposal. It gives you back a complete onboarding package: intake questionnaire, access provisioning checklist, reporting cadence document, and a structured data handoff that plugs directly into the Project Plan Agent to kick off delivery.

This is the agent most Blueprint members deploy first — because the payoff is immediately visible. Onboarding is repetitive, high-stakes (first impressions matter), and follows the same pattern every time. That makes it the perfect candidate for automation.

Why this matters

Bad onboarding kills retention. When a new client signs and doesn't hear from you for three days while you scramble to set things up, they start second-guessing the purchase. This agent eliminates that gap entirely.

How It Works

The Onboarding Agent follows a structured workflow trained on the exact onboarding process we've refined over nine years of running agencies. Here's what happens when you trigger it:

1

Proposal Intake

You provide the signed proposal or deal summary. The agent extracts client name, service scope, contract terms, and any special requirements mentioned during the sales process.

2

Intake Questionnaire Generation

Based on the service scope, the agent generates a customized client intake questionnaire — covering logins, brand guidelines, target markets, competitor lists, historical data access, and anything else needed before delivery can begin.

3

Access Provisioning Checklist

The agent builds a complete access checklist: Google Analytics, Search Console, Google Business Profile, CMS, ad accounts, call tracking — customized to the services in the contract. Nothing gets missed.

4

Reporting Cadence Setup

Based on the contract terms, the agent generates a reporting schedule with deliverable milestones, check-in dates, and a communication cadence document the client can review and approve.

5

Project Plan Agent Handoff

All structured client data is packaged and formatted for the Project Plan Agent, which takes over to build the sprint-based delivery timeline. No manual re-entry required.

Frequently Asked Questions

Do I need to know how to code to use this agent?

No. The Onboarding Agent runs inside Claude's desktop interface. You paste in your proposal, answer a couple of prompts, and the agent generates everything. No coding, no terminal, no technical setup.

Can I customize the intake questionnaire for my niche?

Yes. The agent is trained on a general SEO agency onboarding flow, but you can customize the intake questions, access checklists, and reporting templates to match your specific service. The training walks you through exactly how.

How does it connect to the Project Plan Agent?

The Onboarding Agent outputs a structured data packet — client info, service scope, access status, timeline requirements — that the Project Plan Agent reads as its input. You copy the output into the next agent. No integrations or APIs needed.

How long does onboarding take with this agent?

Most members go from signed proposal to complete onboarding package in under 15 minutes. Without the agent, this same process typically takes 2-3 hours of manual work.
