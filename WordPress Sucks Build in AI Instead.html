The pushback
I know what you’re thinking.
Here are the three objections I hear every time.
Objection 1
“What about security and getting hacked?”
Our WordPress sites got hacked. Always.
  • WordPress hands attackers a database, a login page, and every plugin you install
  • A static HTML site on Vercel has none of those to break into
  • No plugin updates to babysit. No malware cleanups.
Objection 2
“What about tracking and plugins?”
Tell Claude. It handles it.
  • A designer, developer, and analytics specialist in your pocket
  • Need analytics, call tracking, or a form? Describe it and it’s built in.
  • WordPress sites get slow and bloated
  • Plugins are a dated way to manage a website
Objection 3
“We need WordPress to share workflows as a team.”
Have you used Claude artifacts?
  • A Figma board and a code repo in one place
  • Everyone on the team can open it, comment, and edit
  • No staging site, no admin logins, no plugin conflicts
