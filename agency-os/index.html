The Engine
DATA IN. STRATEGY OUT.

Agency OS is built around a single powerful pipeline. Pull live data from your providers, normalize it into observations, generate findings with AI, and produce client-ready artifacts -- automatically.

Pull

Fetch live data from Ahrefs, GSC, GA4, Local Falcon, GBP, and more. Cached and reusable.

Observe

Normalize raw data into typed observations: pages, keywords, rankings, backlinks, citations, reviews.

Analyze

AI generates prioritized findings with severity, impact, effort, and recommended actions. You review and approve.

Deliver

Generate branded workbooks, HTML reports, and decks. Export to Google Drive. Import findings into project plans.

The Analysis Engine
THREE ANALYSIS TYPES. ONE WORKFLOW.

Each analysis pulls live data, generates normalized observations, produces AI-powered findings, and renders client-ready artifacts. You review and approve -- the system does the heavy lifting.

Website Quality Audit

Upload a crawl and the WQA engine classifies every page, scores quality, identifies gaps, and generates prioritized findings with recommended actions.

  • Page classification (money, content, utility, E-E-A-T)
  • Traffic and authority analysis per page
  • Prioritized findings with severity + effort
  • Branded workbook export (XLSX or HTML)

Local SEO Audit

Pull GBP data, Local Falcon grids, citations, reviews, and competitor profiles. Generate findings across NAP consistency, ranking gaps, review velocity, and category optimization.

  • GBP profile completeness scoring
  • Citation consistency across directories
  • Grid-point ranking data with share of voice
  • Competitor benchmarking with DR and review counts

SEO Proposal

Pull Ahrefs metrics, keyword data, and backlink profiles for a prospect. Classify pages, identify opportunities, and generate a branded proposal with competitive positioning.

  • Domain metrics and keyword opportunity gaps
  • Competitive analysis with backlink comparison
  • Data-backed recommendations by priority
  • Branded HTML proposal ready to send

Common Questions
FREQUENTLY ASKED
What exactly is Agency OS?
Agency OS is an AI-powered operating system for SEO agencies. It runs as an MCP server through Claude, backed by a cloud-hosted Postgres database. It gives you a complete system for managing leads, clients, projects, sprints, team workload, analyses (WQA, local SEO, proposals), and finance -- all from natural language conversations.
How is this different from a project management tool?
Project management tools track tasks. Agency OS does the work. It pulls live data from Ahrefs, GSC, GA4, and other providers, normalizes it into observations, generates prioritized findings with AI, and produces client-ready deliverables -- workbooks, reports, and proposals. You review and approve rather than build from scratch.
Where does my data live?
Your data lives in a cloud-hosted Postgres database with row-level security. Each agency gets its own isolated tenant -- your queries only ever see your own data. You can run SQL directly against your agency data at any time through the built-in query engine.
Is Agency OS included in my membership?
Yes. Agency OS, all analysis types, plan templates, integrations, and ongoing updates are included in your Blueprint Training membership at $199/mo. There are no add-ons or premium tiers.
Do I need API keys for the integrations?
API keys are optional and only needed for the specific data providers you want to use. Agency OS works without any integrations -- they unlock additional capabilities like pulling live Ahrefs data into proposals or tracking local rankings via Local Falcon.
What is the pulse report?
The pulse report is your daily command center. One command shows everything that needs human attention: overdue deliverables, stale pipeline leads, blocked analyses, due follow-ups, and team members at capacity. Clients with nothing overdue show as all-clear so you can focus on what matters.
